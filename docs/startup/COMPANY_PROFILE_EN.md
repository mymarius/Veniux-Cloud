# Veniux Cloud product profile

This describes a product, not a verified incorporated company or certified deployment. Veniux Cloud targets retailers and small to mid-sized warehouses in Türkiye. It brings product, inventory, warehouse, lot and sales records into a shared workspace.

The existing scope includes product/barcode records, receiving, locations, transfers, counts, lot/expiry tracking, retail sales/returns, shifts, cost reporting, CRM/team workspaces, access scopes and audit records. Windows uses Electron, Android uses Java/WebView, with a shared React interface. The Node/Express operational backend defaults to SQLite and has an optional MySQL adapter. The marketing site and licensing authority use PHP; no Laravel application was found.

The business model is licensed subscription periods. Revenue, customer count, funding and legal entity details have not been verified. Hardware acceptance, signed Windows distribution and unresolved regression findings remain release gates. No pharmacy/Medula capability, universal printer compatibility or guaranteed offline central licensing is offered.

The roadmap prioritizes access/data integrity, recovery/installation acceptance, real hardware pilots, consent-aware measurement, useful content and approved partnerships. A demo uses synthetic records from product creation through receiving, transfer, sale, return and reporting. Startup applications and cloud resources require separate approval.
